# Hackathon Project

A collaborative project built during the hackathon.

## Project Structure

- **client/** - The React frontend application.
- **server/** - The Node.js/Express backend API.
- **supabase plan.md** - Information about the database and Supabase implementation.

## Getting Started

### Backend

1. Navigate to the `server/` directory.
2. Install dependencies: `npm install`
3. Set up your `.env` file (copy `.env.example` if available).
4. Run the server: `npm start` or `npm run dev`

### Frontend

1. Navigate to the `client/` directory.
2. Install dependencies: `npm install`
3. Set up your `.env` file.
4. Run the development server: `npm run dev`
